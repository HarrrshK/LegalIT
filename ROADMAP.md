# Roadmap

1. **Foundation:** FastAPI settings, SQLite, SQLAlchemy, Alembic, health, local storage, tests.
2. **Identity:** registration, login, durable sessions, profiles, role policy, admin bootstrap, lawyer verification.
3. **Lawyer operations:** client records, cases, notes, tasks, deadlines, documents, activity history.
4. **Client experience:** directory, consultations, relationships, shared workspace, notifications.
5. **Legal data:** source registry, manual permitted ingestion, normalized records, SQLite FTS5, ranking.
6. **AI research:** retrieval, evidence prompt, structured output, citation validation, safe fallback.
7. **News and directory:** source-backed news, preferences, public lawyer pages and filters.
8. **Hardening:** abuse controls, authorization audit, accessibility, backup/restore, complete tests.
9. **Deployment:** static frontend, supervised ASGI service, reverse proxy, HTTPS, persistent disk, operational verification.

Each milestone is complete only after tests, documentation, and `PROJECT_STATUS.md` are updated.
